# Anthony Mays Data Analytics Portfolio

This portfolio highlights synthetic data projects focused on operational reporting, dashboard development, executive-ready insight delivery, and data storytelling.

## Featured Project

### Tableau Dashboard: Synthetic Army Housing Utilization & Vacancy

This interactive Tableau dashboard analyzes occupancy, vacancy, net utilization, open work orders, and low-utilization buildings across fictional installations.

The project demonstrates repeatable leadership reporting, synthetic data preparation, dashboard development, and executive-ready insight delivery for an operational reporting scenario.

## Data Notice

All data in this portfolio is fully synthetic. It does not contain real government, military, personal, operational, or sensitive data.

## Portfolio Purpose

The goal of this portfolio is to demonstrate the ability to:

- Prepare and structure synthetic operational data
- Build dashboard visuals that support leadership review
- Analyze occupancy, vacancy, utilization, and follow-up priorities
- Present insights clearly for non-technical and executive audiences
- Communicate data findings in a practical business context
